# Srivani Golla — Portfolio

A responsive personal portfolio for Srivani Golla, an aspiring SDET focused on software testing, automation, and dependable web experiences. Built with Vue 3 and Vite.

## Run locally

1. Install Node.js (LTS).
2. From this project directory, run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. Run `npm run build` to create a production bundle in `dist/`; use `npm run preview` to inspect that bundle locally.

## Features

- Responsive navigation with a mobile menu and persistent light/dark theme preference.
- Resume PDF generated in the browser from the resume information represented on the portfolio.
- Project showcase with no fabricated repository or demo links.
- Contact form that composes an email in the visitor’s email application; it does not send or store form submissions.
- Keyboard-accessible navigation, visible focus treatment, reduced-motion support, and a skip-to-content link.

## Content and links

Personal details, education, skills, experience, certifications, achievements, and project descriptions were supplied for this portfolio. Social profile destinations use the supplied GitHub, LinkedIn, and LeetCode URLs. No certificate, project repository, or live-demo URLs were supplied, so those actions are not presented as links.
